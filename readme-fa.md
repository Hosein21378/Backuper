# بکاپر چیه؟  
**بکاپر** یک اسکریپت بکاپ‌گیری خودکار با قابلیت سفارشی‌سازی کامل و پشتیبانی از چندین پلتفرم است.  

## پلتفرم‌های پشتیبانی‌شده  

- [x] **Gmail**  
- [x] **Telegram**  
- [x] **Discord**  

## ویژگی‌های کلیدی  

- **بازگردانی بکاپ از همان پلتفرمی که بکاپ ارسال می‌شود (تلگرام / دیسکورد / جیمیل / فایل محلی)**
- **اضافه کردن توضیحات سفارشی**  
- **زمان‌بندی خودکار**  
- **پشتیبانی از چندین قالب**  
- **افزودن/حذف دایرکتوری‌های دلخواه**  
- **ارسال بکاپ بدون محدودیت حجمی**  
- **امکان تعیین رمز عبور برای بکاپ‌ها**  
- **رابط کاربری ساده و کاربردی**  
- **پاکسازی بکاپ‌های قدیمی**  
- **درج تاریخ و ساعت در نام فایل بکاپ**  
- **بهینه‌شده برای عملکرد بهتر**

## بازگردانی بکاپ

بکاپر علاوه بر گرفتن بکاپ، می‌تواند بکاپ را **روی سرور برگرداند**؛ دقیقاً از همان
پلتفرمی که بکاپ به آن ارسال شده است. کافیست اسکریپت را اجرا کنید و گزینه‌ی
`2) Restore Backup` را انتخاب کنید:

```bash
sudo bash -c "$(curl -sL https://github.com/erfjab/Backuper/raw/master/backuper.sh)"
```

یا فقط بخش بازگردانی را اجرا کنید:

```bash
sudo bash -c "$(curl -sL https://github.com/erfjab/Backuper/raw/master/backuper.sh) restore"
```

بازگردانی چه کارهایی انجام می‌دهد؟

- آخرین بکاپ را از **تلگرام**، **دیسکورد**، **جیمیل** یا **فایل محلی** دانلود می‌کند
- بکاپ را به‌صورت خودکار از تاریخچه‌ی ارسال پیدا می‌کند، یا می‌توانید لینک پیام / شناسه‌ی فایل را وارد کنید
- بکاپ‌های تکه‌تکه (`_backuper.z01 ... _backuper.zip`) را تشخیص داده و به‌درستی ادغام می‌کند
- در صورت رمزدار بودن آرشیو، رمز عبور را می‌پرسد
- قبل از بازنویسی، یک نسخه‌ی ایمن از فایل‌های فعلی در `/root/prerestore-*.zip` می‌سازد
- در صورت وجود فایل دیتابیس (`_backuper.sql`) آن را ایمپورت می‌کند
- در پایان پیشنهاد راه‌اندازی مجدد کانتینرهای داکر را می‌دهد

> [!NOTE]
> بازگردانی روی سرور تازه هم ممکن است: گزینه‌ی `Manual restore` را انتخاب کنید و
> توکن ربات / آدرس وبهوک / رمز اپلیکیشن جیمیل را وارد کنید.
