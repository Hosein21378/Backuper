# بکاپر [English](readme.md)

**بکاپر** یک ابزار خودکار برای **گرفتن و بازگردانی بکاپ** پنل‌های VPN است.
بکاپ‌ها را طبق زمان‌بندی می‌گیرد، به تلگرام/دیسکورد/جیمیل می‌فرستد و هر وقت لازم شد
دوباره روی سرور برمی‌گرداند.

## پلتفرم‌های پشتیبانی‌شده

- [x] **تلگرام**
- [x] **دیسکورد**
- [x] **جیمیل**

## ویژگی‌های کلیدی

- **همه‌چیز در یک اسکریپت** — بکاپ، بازگردانی و پنل وب
- **بازگردانی از همان پلتفرمی** که بکاپ ارسال می‌شود (تلگرام / دیسکورد / جیمیل / فایل محلی)
- **پنل وب** — داشبورد، لاگ زنده، بکاپ و بازگردانی با یک کلیک
- **توضیحات (remark) سفارشی** — هر بکاپ نام جداگانه، چند بکاپ روی یک سرور
- **زمان‌بندی خودکار** با کران‌جاب
- **پشتیبانی از چندین قالب** (پنل نصب‌شده روی سرور خودکار شناسایی می‌شود)
- **افزودن/حذف دایرکتوری‌های دلخواه**
- **ارسال بکاپ بدون محدودیت حجمی** (آرشیوهای تکه‌تکه)
- **امکان تعیین رمز عبور برای بکاپ‌ها**
- **پاکسازی بکاپ‌های قدیمی**
- **درج تاریخ و ساعت در نام فایل بکاپ**
- **حالت غیرتعاملی** برای اتوماسیون (`BACKUPER_NONINTERACTIVE=1`)
- **بهینه‌شده برای عملکرد بهتر**

## نصب

اسکریپت را با دسترسی root روی سرور اجرا کنید:

```bash
sudo bash -c "$(curl -sL https://github.com/Hosein21378/Backuper/raw/master/backuper.sh)"
```

سپس از منو یک گزینه انتخاب کنید:

```
======== Backuper Menu [v1.0.0] ========

1) Install Backuper
2) Restore Backup
3) Remove All Backups
4) Run All Backup Scripts
5) Web Panel
6) Exit
```

## بازگردانی بکاپ

بکاپر می‌تواند بکاپ را روی سرور برگرداند؛ دقیقاً از **همان پلتفرمی که بکاپ به آن
ارسال شده است**. گزینه‌ی `2) Restore Backup` را انتخاب کنید، یا مستقیم اجرا کنید:

```bash
sudo bash -c "$(curl -sL https://github.com/Hosein21378/Backuper/raw/master/backuper.sh) restore"
```

بازگردانی چه کارهایی انجام می‌دهد؟

- آخرین بکاپ را از **تلگرام**، **دیسکورد**، **جیمیل** یا **فایل محلی** دانلود می‌کند
- بکاپ را خودکار از تاریخچه‌ی ارسال پیدا می‌کند، یا می‌توانید لینک پیام / شناسه‌ی فایل بدهید
- بکاپ‌های تکه‌تکه (`_backuper.z01 ... _backuper.zip`) را تشخیص داده و درست ادغام می‌کند
- در صورت رمزدار بودن آرشیو، رمز عبور را می‌پرسد
- قبل از بازنویسی، یک نسخه‌ی ایمن از فایل‌های فعلی در `/root/prerestore-*.zip` می‌سازد
- در صورت وجود فایل دیتابیس (`_backuper.sql`) آن را ایمپورت می‌کند
- در پایان پیشنهاد ری‌استارت کانتینرهای داکر را می‌دهد

> بازگردانی روی سرور تازه هم ممکن است: گزینه‌ی `Manual restore` را انتخاب کنید و
> توکن ربات / آدرس وبهوک / رمز اپلیکیشن جیمیل را وارد کنید.

## پنل وب

یک پنل وب سبک و بدون وابستگی (فقط Python 3، بدون نصب پکیج) همراه پروژه است.
پنل فقط یک رابط کاربری روی همان `backuper.sh` است، پس منطق بکاپ تغییر نمی‌کند.

```bash
sudo bash -c "$(curl -sL https://github.com/Hosein21378/Backuper/raw/master/panel/install.sh)"
```

نصب‌کننده در پایان آدرس پنل، نام کاربری و رمز ساخته‌شده را چاپ می‌کند.
از منوی خود اسکریپت هم می‌توانید نصب کنید: گزینه‌ی `5) Web Panel`.

| تب | کاربرد |
|-----|---------|
| **داشبورد** | همه‌ی بکاپ‌های نصب‌شده با مقصد، زمان‌بندی و آخرین اجرا — اجرای فوری، فعال/غیرفعال، مشاهده‌ی لاگ، حذف |
| **بکاپ جدید** | انتخاب قالب (پنل‌های شناسایی‌شده علامت می‌خورند)، بازه‌ی زمانی، پلتفرم و اطلاعات آن، رمز آرشیو و مسیرهای اضافه |
| **بازگردانی** | بازگردانی از تلگرام / دیسکورد / جیمیل / فایل محلی، همراه با کنسول زنده و تأیید |

نکات:

- به‌صورت سرویس **systemd** با نام `backuper-panel` اجرا می‌شود و خودکار ری‌استارت می‌شود
- ورود با **رمز عبور** (کوکی نشست)؛ تغییر رمز با `backuper-panel --set-password`
- خروجی همه‌ی عملیات **زنده** در مرورگر نمایش داده می‌شود و می‌توانید پاسخ سؤال‌ها را هم تایپ کنید
- پنل اسکریپت را در حالت غیرتعاملی اجرا می‌کند که خودتان هم می‌توانید مستقیم استفاده کنید:

```bash
BACKUPER_NONINTERACTIVE=1 \
BACKUPER_REMARK=master BACKUPER_TEMPLATE=1 BACKUPER_TIMER=60 \
BACKUPER_PLATFORM=telegram BACKUPER_TG_TOKEN="..." BACKUPER_TG_CHAT="..." \
bash backuper.sh install
```

> پنل با دسترسی root فایل‌ها را تغییر می‌دهد؛ آن را پشت فایروال یا ریورس‌پروکسی قرار دهید.

## ساختار پروژه

```
backuper.sh                 کل موتور بکاپ و بازگردانی (یک فایل)
panel/backuper-panel.py     پنل وب (فقط کتابخانه‌های استاندارد)
panel/install.sh            نصب‌کننده‌ی پنل (systemd + رمز عبور)
```

## تغییر برند پروژه

همه‌ی موارد مربوط به نام و آدرس پروژه در چند ثابت جمع شده‌اند:

- `backuper.sh` → `PROJECT_NAME`، `PROJECT_OWNER`، `PROJECT_OWNER_LINK`، `GITHUB_REPO`، `REPO_RAW`، `VERSION`
- `panel/backuper-panel.py` → `PRODUCT_NAME`، `REPO_URL`، `VERSION`
- `panel/install.sh` → `REPO_RAW`، `REPO_URL`
